# File Translator

File Translator is a web application that allows you to translate documents and text files with ease. The site is built with Python (backend), HTML, JavaScript, and CSS (frontend), providing a user-friendly interface for converting file contents between languages.

## Features

- Upload files in various formats for translation
- Support for multiple languages
- Fast and secure translation process
- Modern, responsive web design
- No registration required; start translating immediately

## Live Demo

Visit the deployed site: [https://translatefiles.space](https://translatefiles.space)

_Deployed on [Railway](https://railway.app/)_

## Tech Stack

- **Backend:** Python
- **Frontend:** HTML, JavaScript, CSS

## Getting Started

To run the project locally:

1. **Clone the repository**
    ```bash
    git clone https://github.com/muntadhar7/file_translator.git
    cd file_translator
    ```

2. **Set up the environment**
    - Make sure you have Python 3.x installed.
    - (Optional) Create and activate a virtual environment.

3. **Install dependencies**
    ```bash
    pip install -r requirements.txt
    ```
    If using Node.js for frontend tooling, install with:
    ```bash
    npm install
    ```

4. **Run the server**
    ```bash
    python app.py
    ```
    Or follow the instructions in your `Procfile` or Railway config if deploying.

5. **Open your browser:**  
   Go to `http://localhost:5000` (or the port specified) to use the app locally.
